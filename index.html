VK Engineers, Inc. · Website Review

Two directions for the new site.

Same content, same pages, same contact and scheduling flow — two different approaches to design and maintenance. Click into each one and browse it like a visitor would.

Version A — Simple
Clean · Minimal · No JavaScript

The Simple Version

Light, quiet, and utilitarian. Everything on each page is literally in that page's file — what you see is what you edit.

  • Plain HTML + one small stylesheet, no scripts at all
  • Easiest possible manual editing for a non-technical person
  • Projects shown as clean grouped lists (no individual project pages)
  • Trade-off: the menu and footer are repeated in each of the 5 files
Open Version A →
Version B — Advanced
Editorial · Illustrated · Interactive

The Advanced Version

Dark, editorial, and visually rich — custom structural illustrations, scroll animations, hover previews, and a filterable project gallery with a page for every project.

  • Shared menu & footer — edit once, updates all pages
  • Project list lives in one data file; each project gets its own page
  • Animated stats, scroll-reveal sections, hover details
  • Trade-off: a little more structure to learn before editing
Open Version B →
For whoever maintains the site later: both versions are plain files that open in any text editor. The README.md in this folder explains exactly which file to open to change what, for each version. To go live, upload the contents of the chosen folder (simple/ or advanced/) as the website — not this comparison page.
